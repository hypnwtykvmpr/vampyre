# Vampyre 0.9.5

Vampyre 0.9.5 is the first standalone repository release. It preserves keyed
directed multigraph state across extraction, updates, exports, hooks, and MCP
serving, and includes the production-hardening and cross-platform work completed
through this release tag.

The repository is detached from its former fork network. The canonical source,
documentation, security policy, and release assets are maintained only at
https://github.com/hypnwtykvmpr/vampyre; no parent repository is a Vampyre
update, support, or release channel.

## Highlights

- Strict graph-state validation prevents silent class changes, parallel-edge
  collapse, rival graph creation, and updates against ambiguous source roots.
- Deterministic extraction, clustering, serialization, and repeated updates are
  enforced by regression tests and graph-health gates.
- Semantic egress blocks credential-classified content before any configured LLM
  provider receives it, including nested and multiline configuration shapes.
- HTTP MCP serving is loopback-only without authentication. Non-loopback binds
  require an API key, TLS certificate and key, and explicit host controls.
- Windows, macOS, and Linux run the full strict suite in hosted CI. Release
  bundles install the same universal wheel and execute the real CLI on each OS.
- Query logging is opt-in and disabled by default.
- Outdated inherited translated READMEs were retired rather than publishing
  incorrect branding, support, feature, and installation guidance. English is
  authoritative until maintained Vampyre translations are reviewed against a
  tagged release.

## Assets

- `graphifyy-0.9.5-py3-none-any.whl`: universal Python wheel.
- `graphifyy-0.9.5.tar.gz`: source distribution.
- `vampyre-0.9.5-windows.zip`: wheel plus PowerShell installer, tested on Windows.
- `vampyre-0.9.5-macos.tar.gz`: wheel plus shell installer, tested on macOS.
- `vampyre-0.9.5-linux.tar.gz`: wheel plus shell installer, tested on Linux.
- `vampyre-0.9.5-self-graph.tar.gz`: graph, report, and HTML viewer for Vampyre.
- `SHA256SUMS`: SHA-256 digest for every release asset.

Install from an OS bundle, or install the exact source tag with uv:

```sh
uv tool install --force "graphifyy @ git+https://github.com/hypnwtykvmpr/vampyre.git@v0.9.5"
```

No version newer than 0.9.5 is implied by this release.
